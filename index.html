REAL-WORLD VAPT FINDINGS

Featured Security Case Studies

Detailed breakdowns of critical vulnerabilities discovered, exploited, and successfully driven to full remediation in enterprise environments.

CRITICAL SEVERITY FINTECH / BANKING

Banking Platform: Universal Transaction PIN Bypass

During a comprehensive cross-platform assessment (Web, Android, and iOS) of a premier banking application, uncovered a flaw in the financial authorization routine.

Exploitation Mechanics:

By intercepting the high-value funds transfer request in Burp Suite and stripping the auth_token_pin parameter while altering response flags, the transaction executed unconditionally without verifying the user's secret transaction PIN.

Remediation Implemented:

Enforced strict server-side state machines, cryptographic nonces tied to hardware tokens, and zero-trust parameter validation.

Platform: Web, Android, iOS Status: 100% Remediated
CRITICAL SEVERITY AUTOMOTIVE / EV APPS

Full Account Takeover via Response Manipulation

Discovered authentication bypass flaws within financial and electric vehicle (EV) charging ecosystem applications that allowed taking over arbitrary customer accounts.

Exploitation Mechanics:

Intercepted the password-change OTP verification step. Modifying the server response payload from {"status": false, "code": 401} to {"status": true, "code": 200} tricked the mobile client into presenting the new-password entry screen, resetting the victim's credentials without valid 2FA.

Remediation Implemented:

Migrated session progression entirely to server-side short-lived authorization grants and verified tokens on subsequent commit requests.

Platform: Mobile App / REST API Status: 100% Remediated
HIGH SEVERITY ENTERPRISE SAAS

Mass PII & Sensitive Transaction Exposure via IDOR

Identified critical Insecure Direct Object Reference (IDOR) vulnerabilities across multi-tenant API endpoints exposing personally identifiable information (PII).

Exploitation Mechanics:

By incrementing sequential customer IDs in API endpoints /api/v1/orders/{id}/details without object-level permission validation, any authenticated low-privilege user could extract all customers' full names, phone numbers, addresses, and transaction histories.

Remediation Implemented:

Implemented context-aware tenancy checks, replaced sequential IDs with UUIDv4, and enforced database row-level security (RLS).

Platform: Cloud API / Microservices Status: 100% Remediated
RED TEAM SIMULATION MULTI-CLOUD & AD

Hybrid Cloud & Active Directory Privilege Escalation

Executed simulated adversary campaigns mapped to MITRE ATT&CK for Cloud (AWS, Azure) and on-premise Windows Server Active Directory topologies.

Exploitation Mechanics:

Discovered exposed EC2 metadata credentials leading to IAM privilege escalation, followed by pivoting into connected on-premise Active Directory via Kerberoasting and abusing unconstrained delegation to reach Domain Admin privileges.

Remediation Implemented:

Enforced IMDSv2 across cloud infrastructure, implemented tiered administrative models in AD, and integrated Cortex XDR telemetry.

Platform: AWS, Azure, Active Directory Status: Controls Validated
